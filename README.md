\# 🎲 7 Up 7 Down Game



A command-line dice betting game built in Python. Players place a bet on the total sum of two six-sided dice rolls—guessing whether the total will be \*\*More than 7 (Up)\*\*, \*\*Less than 7 (Down)\*\*, or \*\*Exactly 7\*\*.



\## 📌 Project Overview



This project demonstrates core programming concepts such as:

\- Importing and using Python's `random` module

\- Conditional branching (`if-elif-else`)

\- Input validation and string formatting

\- Recursive function calls for game loops



\## ⚙️ How It Works



1\. The program generates two random integers between 1 and 6 using `randint(1, 6)`.

2\. The user is prompted to enter a guess (`up`, `down`, or `7`).

3\. Input is validated against accepted choices.

4\. The sum of the two dice is calculated and compared against the user's guess to determine the outcome.

5\. The player is asked if they want to play another round.
